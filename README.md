# Prototype
プロトタイプ・Unityの練習・前準備として使います。

### Unity作業前の基本手順

1.	Unityを開く前に  
	→GitHub Desktopを開いておく！  

2.	まずはPull, Fetch Origin！  
	→最新の状態を必ず取り込もう！  

3.	新しいブランチを作ろう！  
	→作業内容ごとにブランチを分けるのが基本  

4.	ブランチ名をもう一度チェック！  
	→間違ってmainで作業してない？確認！  

5.	Unityで作業・変更！  
	→作業が一区切りついたら、こまめに Commit & Push！  

6.	作業が終わったらUnityを閉じてからPush！  
	→保存漏れやファイルロックを防げます！  

7.	最後に Pull Request を作成！  
	→GitHub サイト上でプルリクを送ろう！  

8.	Pull Requestには簡単な説明をつけよう！  
	→どんな変更をしたのか具体的に書いておく！
