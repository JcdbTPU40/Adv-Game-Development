本質的経験新規

Lens #1 本質的経験／#2 驚き：プレイヤーに何を感じ、何を考え、何をしたと記憶してほしいかを一文で言えるか。

次々に訪れる願いの優先度と、救った後に広がる福を見比べ、いま救うひとりを選び、大幣で狙って願いを届ける気持ちよさ。

この一文には行為（色を選び、狙い、振る）、判断（誰を今救うか）、 感情（間一髪の爽快感と、笑顔が広がる安堵）、結果（ひとりの救済が次の救済を助ける）の4層があります。 以降の仕様は「この体験の頻度・強度・理解のどれを上げるか」を説明できる場合だけ採用します。

なぜ書き直したか

v4のコンセプトは「光った色を見分けて素早く選び、狙って投げ当てる爽快感」でしたが、 これには判断が入っていません。一方で2章には「腕前の軸は投擲精度＋優先順位判断」と 書いてあり、文書内で食い違っていました。 判断を実際に発生させる仕組み（最危険の1人を救う優先救済+50と、笑顔の伝播 → 7章）を入れたうえで、 本質的経験の一文に判断を組み込みました。

テーマ（中心的な問い）新規

Lens #9 統一／#10 共鳴：テーマは題材ではなく、作品が一貫して探究する問いや感情。

ひとりを救った喜びは、次のひとりへ福として伝わっていく。

中心的な問いは「目の前のひとりへの判断が、どこまで場全体の福を広げられるか」。 競争や得点を否定するテーマではない。縁の基礎点は救済完了時だけ生まれ、正確さ・優先判断・笑顔の伝播で上乗せされる。 途中命中や誤色からは縁を出さず、高得点ほど「多くの願いを、正確に、間に合う順で届け、次へ福をつないだ」記録になるようルールを揃える。

  • 救済すると参拝客が笑顔で帰り、その笑顔が他の参拝客にも伝わる（→ 6章）
  • 救えなかった参拝客は怒って黒くなり、境内に居残って邪魔になる＝叶えられなかったことの痛み
  • スコア「縁」は、救済・正確な一投・笑顔の伝播で増え、境内を明るくする
  • プレイヤーは巫女の姿を借りた神。ご加護タイムは神としての力を一瞬取り戻す演出

見比べる

二重円・距離・必要発数・伝播経路を読み、「今のひとり」を選ぶ。

届ける

構え、狙い、振る。入力から100ms以内に音・軌跡・振動が返る。

広がる

笑顔が別の参拝客の時間を生み、縁と灯りが境内へ残る。

コア体験を守る禁止事項MVP

  • 狙わない連打、最寄りだけを撃つ、大祓だけを待つ行動が最高効率になってはならない。
  • 外れた理由をプレイヤーが「入力・狙い・色」のいずれかへ帰属できない妨害を入れない。
  • 最初の30秒に、ボス・大祓・天候効果・ランク変動・複数発ゲージを同時提示しない。
  • 投げる1回の反応を待たせる演出、操作を止める演出、読み終える必要がある長文UIを入れない。

投擲（強さ）

  • 振り下ろす動作が発射のトリガー
  • 振りの速さは飛翔時間と軌跡の太さに反映する。最遠距離でも0.65秒以内に着弾し、着弾位置はSwingAccepted時の照準で決まる
  • 弾道は開始点と着弾点を結ぶ演出用スプライン。現実の放物運動は再現せず、強く振っても着弾点はずれない

位置を強さで決めると狙いが安定せず、子どもには当てられない。強さは気持ちよさに使い、正確さは向きに持たせる。

弾数とクールダウン新規

  • 弾は無限。弾数管理・リロードはしない
  • 発射のクールダウンは再検出禁止時間と同値。基準0.50秒、T0-CDで0.40〜0.65から決定する 変更
なぜこうするか

弾を有限にすると「弾切れで何もできない時間」が生まれ、3分の試遊で最も避けたい空白になります。 一方でクールダウンが無いと、狙わず連射するのが最適解になり投擲精度という腕前の軸が消えます。 「1発を外すとクールダウンぶん損する」という重みを作ります。 v3の「弾の無駄消費」というペナルティ表現は、このクールダウン分の時間損失に置き換えます。

v6は0.60秒を固定値としていましたが、その根拠は「再検出禁止時間と揃えた」だけでした。 0.60秒だと毎秒1.67発が上限で、終盤の負荷ウェーブに人数が追いつかない計算になります（→ 8章）。 v8では値ではなく決め方を仕様とし、重複誤発射と意図的連投欠落がともに2%以下となる最小値をT0-CDで選びます。

13観戦と展示運用新規

Lens #21 社会：社会的な楽しさは勝敗だけでなく、観戦・共有まで含む。

なぜこの章があるか

展示会では1台の前に遊んでいる1人と待っている5〜10人がいます。 つまり体験している人の大半は観戦者です。v4には観戦者向けの設計が何もありませんでした。

観戦体験の設計

  • 大幣を振る動作そのものが大きいので、そこは既に観戦向き。この強みを潰さない（小さく振れば当たる設計にしない）
  • 命中エフェクトを大きめにする（外から見て当たったと分かる）
  • 救済成功時の鈴の音を強めに鳴らす。音は列の後ろまで届く
  • 画面右上に「今日のベストスコア」と「今のスコア」を並べる（待っている子が「勝てそう」と思える）
  • 縁と現在ランクはMVPでも画面外から読める大きさにする。提灯で画面が明るくなる表現は追加演出で、未採用時も観戦情報を失わない

安全領域と配線MVP

  • プレイヤーの立ち位置を床マットで固定し、前後左右へ各1.5mを振り抜き安全領域としてコーンまたはベルトで囲う。観戦列とアテンド待機位置は後方2m以上、かつ領域外
  • 大幣の全長＋最大腕長で実地確認し、紙垂を含む先端が境界へ届く場合は境界を広げる。子どもが領域を出たら即時停止する
  • USBはボタン箱・大幣からプレイヤー後方へ逃がし、台の脚へ二点でストレインリリーフする。床を横切る部分はケーブルカバーで固定し、振り抜き領域と通路を横断させない
  • 開場前と各休憩後に、床マット、ストラップ、接合部、ケーブルカバー、USB端子をチェックリストで確認する
