1. シーンを Play し、体数を `3`（16体）にする
2. `O` で Outline ON、`F` で晴天（Rain OFF）を確認して `P` → 完了ログを控える
3. `F` で雨天 ON にして `P`
4. `O` で Outline OFF にして、晴天 / 雨天それぞれ `P`（ベースライン）
5. 必要なら体数 8 / 12 でも同様に取る
6. 最後に `C` で CSV を書き出す

## 4. 60fps を満たさなかった場合の軽量化選択肢

効果の目安は相対的。実機で ON/OFF 差分を取り直してから採用すること。

| 手段 | 期待効果 | トレードオフ | 推奨度（仮） |
|---|---|---|---|
| マスクRT解像度を 1/2 | GPU・帯域ダウン大。Compose のダイレートも軽くなる | 縁がジャギーになる。細い輪郭で目立つ | 高（まずここ） |
| マスクRT解像度を 1/4 | さらに軽い | 品質低下が大きい。遠帯では潰れる可能性 | 中（1/2 で足りないとき） |
| ダイレート半径を下げる | Compose のサンプル数が二乗で減る | 輪郭が細くなり #44 の視認性を損なう | 高 |
| ダイレートを2パス分離（横→縦） | 半径 R で O(R²)→O(R) | 実装コスト・中間RTが1枚増える | 中（半径を保てないとき） |
| 遠帯の客の輪郭を細くする / 間引く | 16体フル描画を避ける | 遠方の識別性が落ちる（#44 の論点と衝突） | 低〜中（最終手段） |
| SSAO Renderer Feature を切る | ベースライン自体が軽くなる | 画面の立体感が減る。Outline 純コストとは別枠 | 高（余力確保） |
| レンダースケール / 解像度を下げる | 全体の GPU 負荷が下がる | UI・輪郭とも解像感が落ちる | 中 |
| 影の解像度・カスケード段数を下げる | 影パスが軽くなる | 影のにじみ。Outline とは独立 | 中 |

### 推奨の当たり順（仮）

1. **マスクRT 1/2** と **ダイレート半径の見直し**（見た目への影響が限定的で効きやすい）
2. それでも足りなければ **SSAO OFF** や影品質ダウンでベースラインを稼ぐ
3. それでもダメなら **2パスダイレート** か **遠帯の間引き** を検討（仕様判断が必要）

### 遮蔽の仕組み（要約）

- Mask: カメラ depth-stencil をバインドし `ZTest LEqual` → Opaque 後の深度で遮蔽物の裏は落ちる
- 同時に `Stencil Ref 1 / Replace` で内側をマーク
- Compose: `Stencil NotEqual` で内側を除外し、マスクのダイレート外周だけを合成
