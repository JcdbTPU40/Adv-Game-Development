# 照準・着弾予測点と弾の飛翔（0.25〜0.65 秒）— Issue #60

> 仕様書 v8 4章・5章。狙いは**向き**（ヨー＝左右／ピッチ＝地面上 3〜18m）だけで決め、
> 振りの**強さ**は飛翔時間と軌跡の太さにだけ反映する。着弾予測点と実着弾点を一致させ、
> 子どもが 3 分で上達を実感できるようにする。

## 1. 照準（`OnusaAimController`）

| 入力 | 照準への反映 | 既定値 |
|---|---|---|
| ヨー（`ThrowInputController.RelativeYaw`） | 正面（開始時のカメラ前方）からの左右角。±`maxYaw` で制限 | ±60° |
| ピッチ（`RawSource.Pitch`） | `pitchAtNear`〜`pitchAtFar` を `nearDistance`〜`farDistance` へ線形に正規化。範囲外は端に張り付く | −30°→3m、+20°→18m |
| マウス（机上確認用） | カーソルが指す地面を、上と同じヨー／距離の範囲に収める | — |
| 振りの強さ | **使わない** | — |

- `mode`: `Auto`（ESP32 接続中はヨー／ピッチ、それ以外はマウス）／`Mouse`／`YawPitch`
- 距離は基準点（`origin` = `ShootPos`）からの水平距離。着弾予測点は高さ `groundY` の地面に置く。
- **画面外の押し戻し**: 予測点がビューポートの縁から `viewportMargin`（6%）より外なら、縁の内側の点から地面へレイを落として置き直す。押し戻しは距離範囲より優先する。
- ピッチの符号（BNO055 の取り付け向き）が逆なら `pitchAtNear` と `pitchAtFar` を入れ替える。
- 実行順は `-150`。`ThrowInputController`（`-100`）が SwingAccepted を出す前に、その フレームの予測点が確定している。

### 1.1 着弾目標点の固定

- SwingAccepted の瞬間に `GetLockedTarget(e.Time)` で着弾目標点を決め、弾に渡したら以後は動かさない。
- `lockLookbackSeconds`（既定 0）は「確定の何秒前の照準を使うか」。0 が仕様どおり。
  実機で振りの途中にピッチが動いて狙いが手前にずれる場合に、T0 で 0.05〜0.15 秒程度を試す調整用。

## 3. 弾の飛翔（`OnusaThrower` → `OmamoriProjectile`）

| 項目 | 規則 |
|---|---|
| 弾道 | 開始点（`spawnPoint`）と着弾目標点を結ぶ 2 次ベジェ。弧の高さは水平距離 × 0.12（上限 2m）で**見た目だけ** |
| 着弾点 | **t = 1 で着弾目標点そのもの**を返す。放物運動・物理は使わない |
| 飛翔時間 | 強さ `slowStrength`（180 度/秒）以下 → **0.65 秒**、`fastStrength`（720 度/秒）以上 → **0.25 秒**、間は線形。距離に依存しない。設定値を範囲外にしても 0.25〜0.65 秒に収める |
| 軌跡の太さ | 同じ強さで 0.05 → 0.22 |
| 弾数 | 無限（SwingAccepted ごとに 1 発） |
| 見た目 | `projectilePrefab`（`Bullet.prefab`）から Rigidbody / Collider / OmamoriBullet を外して使う。未設定なら球 |

- マウスのクリックは強さ 1 → 0.65 秒。**Shift を押しながらクリック**で強さ 720 → 0.25 秒（`KeyboardMouseRawSource` / `Esp32RawSource` の未接続時）。
- `KeyboardMouseRawSource` はマウスホイールでピッチを変えられる（`mode = YawPitch` で机上確認）。
- 大祓（`ThrowKind.Oharae`）は発射しない（T5 通過後）。

## 4. 着弾判定

1. 着弾の瞬間、`HitZoneTarget.Active`（有効な参拝客）を候補にする。
2. **当たり判定が消えている客は候補から外す**（結末確定＝救済演出中は `CustomerMood` が Collider を切る → `HitZoneTarget.IsHittable == false`）。弾は通過し、後方の客で判定される。
3. 着弾点と判定中心の**水平距離 ÷ 判定半径**（`outerRadius`、既定 0.9）が 1 以下の客のうち、割合が最も小さい客に当たる。
4. 誰にも当たらなければ外し（`RegisterMiss`）。
5. 途中の客に遮られることはない（予測点と実着弾点を一致させるため）。
6. セッション外（リザルト中）に着いた弾は計上しない。

### 4.1 命中精度

| 判定半径に対する割合 | ゾーン | ボーナス |
|---|---|---|
| 40% 以内 | `Center` | **+50** |
| 40〜70% | `Inner` | **+20** |
| 70〜100% | `Outer` | **+0** |
| 100% 超 | 外し | — |

獲得縁 = (`hitScore` 100 + ボーナス) × コンボ倍率 × ご加護倍率 × 神社評価倍率。相性✗は従来どおり Miss（コンボ途切れ）。

- `ScoreManager` の `outerScore / innerScore / centerScore`（100/200/300）を廃止し、`hitScore`（旧 `outerScore` の値を `FormerlySerializedAs` で引き継ぐ）と `centerBonus / innerBonus / outerBonus` に置き換えた。
- `HitZoneTarget` の `centerRadius / innerRadius` を廃止し、`outerRadius` に対する 40% / 70% で判定する（物理衝突の `OmamoriBullet` も同じ割合）。

## 5. クールダウン中の有効スイング

`SwingRejected`（`Reason == Cooldown`）を受けたとき：

| 返し | 実装 |
|---|---|
| 弾を作らない・得点イベントなし | 状態機械が SwingAccepted を出さない（#51 S4） |
| 照準を 80ms 灰色 | `OnusaThrower` → `AimReticleView.FlashRejected()` |
| 短い低音 | `ThrowInputController.cooldownRejectSe`。未設定なら 110Hz・0.12 秒を合成（`synthesizeRejectSe`） |

## 6. シーンへの組み込み

1. 対象シーンを開く（例: `Assets/Members/Jungaya/Scenes/TestGame.unity`）
2. メニュー `Toufuku/Aim/Setup Aim And Flight In Active Scene`
   - `ThrowInputController` が無ければ、先に `Toufuku/Input/Setup Throw Input In Active Scene` を実行する
   - `OnusaAim` GameObject に `OnusaAimController` ＋ `AimReticleView` ＋ `OnusaThrower` を付けて結線
   - `TestShooter` の `spawnPoint` と `bulletPrefab` を引き継ぎ、**`TestShooter` を無効化**（二重発射防止）
   - `ThrowInputController.aim` を結線（`OnusaAim` 旧スクリプトの向きも照準に追従する）
3. `OnusaAimController` の `groundY` を地面の高さに合わせる（TestGame の Plane は 0）
4. 問題なければシーンを保存

## 8. 前提・未決事項

- 仕様書 v8 本文はリポジトリに無いため、Issue #60 の記述から次のように解釈した。仕様書と照合してほしい：
  1. **命中精度の「+50 / +20 / +0」は基礎点への加算ボーナス**とし、基礎点は従来の外周の点（100）を引き継いだ
  2. 「中心 40%」は**判定半径（`HitZoneTarget.outerRadius`）に対する水平距離の割合**とした
  3. 判定円が重なったときは**中心に近い客**に当てる（手前の客を優先しない）
  4. 飛翔時間は**強さだけで決め、距離には依存しない**（最遠でも 0.65 秒以内を常に満たす）
- ピッチ角の範囲（−30°〜+20°）は仮。実機で「無理なく構えられる角度」を T0 で決める。
- `lockLookbackSeconds` は実機で振りピーク時のピッチのずれを見てから決める。
- 照準マーク・地面の輪・軌跡の見た目と低音は仮素材（#64 の素材待ち）。
